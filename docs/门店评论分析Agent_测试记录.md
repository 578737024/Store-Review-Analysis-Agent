# 项目3：门店评论分析与自动回复 Agent 测试记录

## 一、测试目标

本测试用于验证“门店评论分析与自动回复 Agent”是否能够基于门店评论数据，完成评论统计、差评筛选、问题分类、经营周报生成和差评回复建议。

本项目采用 Python + Coze 的组合方式：

- Python 负责读取 CSV、统计评分、筛选差评、评论分类和生成结构化输入；
- Coze 负责基于结构化数据生成经营分析周报、改进建议和商家回复话术。

---

## 二、测试数据说明

测试数据文件：store_reviews.csv

字段包括：

- review_id：评论编号
- date：评论日期
- store_name：门店名称
- rating：评分
- content：评论内容
- category：评论分类

当前测试数据共 20 条评论，覆盖好评、中评和差评。

基础统计结果：

- 评论总数：20
- 平均评分：3.1
- 好评数量：9
- 中评数量：3
- 差评数量：8
- 好评占比：45.0%
- 中评占比：15.0%
- 差评占比：40.0%

---

## 三、Python 数据处理测试

### 1. 基础统计

Python 脚本能够读取 CSV 文件，并输出：

- 评论总数；
- 平均评分；
- 好评数量；
- 中评数量；
- 差评数量；
- 好评 / 中评 / 差评占比。

### 2. 差评筛选

系统将评分小于等于 2 分的评论识别为差评，并导出：

```text
output/negative_reviews_classified.csv
```

本轮测试共筛选出 8 条差评。

### 3. 评论分类
系统通过关键词规则对评论进行分类，分类包括：
* 配送物流
* 等待时间
* 服务态度
* 环境卫生
* 产品质量
* 价格问题
* 空间体验
* 其他

### 4. 问题分布统计
系统导出两个统计文件：
* `output/category_summary.csv`
* `output/negative_category_summary.csv`

**差评问题分类统计结果：**
* **配送物流：** 2条，占比25.0%
* **等待时间：** 2条，占比25.0%
* **环境卫生：** 2条，占比25.0%
* **服务态度：** 1条，占比12.5%
* **产品质量：** 1条，占比12.5%

**测试结论：**
差评主要集中在配送物流、等待时间和环境卫生三个方向，三类问题合计占差评总数的 75%。

---

## 四、 Coze 经营周报生成测试

### 1. 测试输入
Python 脚本生成了结构化输入文件：`output/coze_weekly_report_input.md`

该文件包含：
* 基础评论统计
* 全部评论分类统计
* 差评问题分类统计
* 典型差评明细
* 给 Coze 的经营分析任务

### 2. Coze 输出结果
Coze 根据结构化输入生成了门店评论分析周报，内容包括：
* 本周评论整体概况
* 差评主要问题
* 每类问题原因分析
* 优先改进建议
* 典型差评回复建议
* 下周运营重点
* 总结

### 3. 输出效果评估

**做得好的地方：**
* 能引用具体数据，如评论总数、平均评分、差评占比；
* 能识别配送物流、等待时间、环境卫生是主要差评问题；
* 能针对典型差评生成回复建议；
* 能输出具体运营动作，如外卖包装复核、卫生巡检、出餐复核；
* 输出结构适合用于门店周报。

**需要优化的地方：**
* 初始版本商家回复中出现“已经整改”的表达，存在虚构处理结果风险；
* 后续通过增加“整改事实边界规则”，限制智能体不能编造门店已经采取的措施；
* 当前分类主要基于关键词规则，遇到复杂语义时可能分类不准确，后续可接入 AI 分类或人工校验机制。

## 五、 典型输出摘要
本轮测试中，Coze 判断当前门店最需要优先解决的问题是：
1. 配送物流
2. 等待时间
3. 环境卫生

**原因分析：**
这三类问题各出现 2 条差评，各占差评总数 25%，合计占比 75%。

**系统建议门店优先优化：**
* 外卖包装密封和出餐核对；
* 高峰期出餐效率和重做订单优先级；
* 门店桌面、地面和公共区域卫生巡检；
* 服务话术和产品出品稳定性。

## 六、 测试结论
本轮测试说明，项目已经完成**“评论数据处理 + AI 经营分析”**的基础闭环。

Python 部分能够完成评论读取、评分统计、差评筛选、规则分类和结构化输入生成；Coze 部分能够基于结构化数据生成门店经营周报、差评原因分析、改进建议和回复话术。

该项目可以作为 AI 应用方向作品，证明候选人具备 **Python 数据处理、业务场景拆解、Prompt 设计、AI 分析报告生成和门店运营场景理解能力**。
