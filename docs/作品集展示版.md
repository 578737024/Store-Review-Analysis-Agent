# 门店评论分析与自动回复 Agent

## 项目简介

门店评论分析与自动回复 Agent 是一个面向咖啡店、餐饮门店等本地生活场景的 AI 应用项目。

项目最初基于 Python + Pandas 对门店评论 CSV 进行数据处理，包括评论统计、差评筛选、问题分类和经营分析输入生成。后续进一步使用 FastAPI 将评论分析能力封装为 API 服务，并部署到 Render 公网环境，最终通过 Dify 工作流调用公网 API，由 LLM 自动生成门店经营分析周报和典型差评回复建议。

本项目不是直接让大模型分析原始评论，而是先通过 Python 对评论数据进行结构化处理，再通过 API 将数据分析能力暴露给 Dify 工作流，最后由大模型基于结构化结果生成业务报告。

## 核心功能

1. 评论数据读取  
使用 Python / Pandas 读取门店评论 CSV，检查字段完整性并进行基础数据处理。

2. 基础评分统计  
统计评论总数、平均评分、好评数量、中评数量、差评数量及对应占比。

3. 差评筛选  
将评分小于等于 2 分的评论识别为差评，并导出差评明细表。

4. 评论问题分类  
基于关键词规则，将评论分类为配送物流、等待时间、服务态度、环境卫生、产品质量、价格问题、空间体验等类别。

5. 问题分布统计  
统计全部评论和差评中的问题分布，识别门店最需要优先改进的问题。

6. FastAPI 接口封装  
将原本只能本地运行的 Python 评论分析逻辑封装为 API，支持 JSON 请求和 CSV 文件上传。

7. Render 公网部署  
将 FastAPI 服务部署到 Render，使外部系统可以通过公网 HTTP 请求调用评论分析能力。

8. Dify 工作流联动  
在 Dify 中通过 HTTP 请求节点调用公网 API，再由 LLM 节点根据 API 返回的 Markdown 分析文本生成门店经营分析周报。

9. 商家回复建议生成  
基于典型差评内容生成商家回复话术，并通过 Prompt 规则限制虚构整改、退款、赔偿、免单等高风险表达。

## 测试结果

测试数据共 20 条门店评论。

基础统计结果：
- 评论总数：20
- 平均评分：3.1
- 好评数量：9
- 中评数量：3
- 差评数量：8
- 差评占比：40.0%

差评主要集中问题：
- 配送物流：2 条，占比 25.0%
- 等待时间：2 条，占比 25.0%
- 环境卫生：2 条，占比 25.0%

这三类问题合计占差评总数的 75%，是门店下周优先改进方向。

## 项目亮点

- 使用 Python / Pandas 完成评论数据读取、统计、分类和结构化输入生成；
- 不直接让 AI 分析原始评论，而是先做结构化数据处理，提高输出依据；
- 使用 FastAPI 将 Python 评论分析逻辑封装为 API 服务，支持 JSON 请求和 CSV 文件上传；
- 将 FastAPI 服务部署到 Render 公网环境，使外部系统可以通过 HTTP 请求调用；
- 在 Dify 中通过 HTTP 请求节点调用公网 API，并由 LLM 节点生成经营分析周报；
- 商家回复加入边界控制，避免虚构“已经整改”、退款、赔偿、免单等承诺；
- 项目覆盖数据处理、API 封装、公网部署、工作流调用和 AI 报告生成完整链路。

## 当前局限

- 当前测试数据量较小，主要用于项目演示；
- 评论分类仍以关键词规则为主，复杂语义下可能存在误判；
- Dify 当前测试主要使用 JSON 请求调用 API，文件上传工作流仍可继续优化；
- 暂未接入真实门店评论平台；
- 暂未加入数据库保存历史分析记录；
- 暂未制作面向普通用户的前端上传页面。
