# 门店评论分析与自动回复 Agent

## 项目简介

基于 Python + Coze 搭建的门店评论分析与自动回复 Agent，面向咖啡店、餐饮门店等本地生活场景，支持评论数据统计、差评筛选、问题分类、经营周报生成和商家回复建议。

项目不是直接让大模型分析原始评论，而是先用 Python 对评论 CSV 进行结构化处理，再将统计结果输入 Coze，由智能体生成门店运营分析报告和差评回复话术。

## 核心功能

1. 评论数据读取  
使用 Python 读取门店评论 CSV，检查字段完整性并进行基础数据处理。

2. 基础评分统计  
统计评论总数、平均评分、好评数量、中评数量、差评数量及对应占比。

3. 差评筛选  
将评分小于等于 2 分的评论识别为差评，并导出差评明细表。

4. 评论问题分类  
基于关键词规则，将评论分类为配送物流、等待时间、服务态度、环境卫生、产品质量、价格问题、空间体验等类别。

5. 问题分布统计  
统计全部评论和差评中的问题分布，识别门店最需要优先改进的问题。

6. Coze 经营周报生成  
将 Python 生成的结构化分析结果输入 Coze，由智能体生成经营周报、改进建议和商家回复话术。

## 测试结果

测试数据共 20 条门店评论。

基础统计结果：

- 评论总数：20
- 平均评分：3.1
- 好评数量：9
- 中评数量：3
- 差评数量：8
- 差评占比：40.0%

差评主要集中问题：

- 配送物流：2 条，占比 25.0%
- 等待时间：2 条，占比 25.0%
- 环境卫生：2 条，占比 25.0%

这三类问题合计占差评总数的 75%，是门店下周优先改进方向。

## 项目亮点

- 使用 Python 完成评论数据读取、统计、分类和结构化输入生成；
- 使用 Coze 生成门店经营周报和差评回复建议；
- 不直接让 AI 分析原始评论，而是先做结构化数据处理，提高输出依据；
- 商家回复加入边界控制，避免虚构“已经整改”、退款、赔偿、免单等承诺；
- 项目覆盖数据处理、业务分析、Prompt 设计和 AI 应用落地能力。
